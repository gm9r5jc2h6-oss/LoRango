# Reference asset provenance

- `inputs/utility_s.safetensors` and `inputs/utility_p.safetensors` were
  trained by the authors as the two benign SDXL cover adapters used in the
  experiments.
- `outputs/modified_s.safetensors` and `outputs/modified_p.safetensors` are
  historical author-generated Pair-2 exports derived from those covers.
- `checkpoint/checkpoint_legacy.safetensors` and its JSON sidecar are the
  non-deployable warm-start state. The sidecar records the SHA-256 of the
  original author-generated v1.2 `.pt` and the restricted, no-Torch migration.
  The unsafe legacy file is not distributed or loaded by v1.4.
- `train_data.json` contains author-written prompts and no external dataset
  records.
- `images/overview.png` was generated by the authors from the reference model
  and adapters.
- SDXL Base 1.0 is not included. Reviewers must obtain it under its upstream
  model license and verify the exact loaded files against
  `MODEL_MANIFEST.json`.

The code is Apache-2.0. Model-derived weights and generated media remain
subject to the applicable upstream model license in addition to the research
artifact's disclosure and use constraints.
